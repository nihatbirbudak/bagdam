# ADR-0019: Ödeme sağlayıcısı PayTR (birincil); iyzico ikincil/P2

- **Tarih:** 2026-08-20
- **Durum:** Kabul edildi — ADR-0010'un "ilk sağlayıcı iyzico" kısmının yerini alır (arayüz/strateji kararları geçerli)
- **Bağlam:** Kullanıcı kararı: ödemede büyük olasılıkla PayTR ile ilerlenecek. `PaymentProvider` arayüzü + `ChargeStrategy` (MERCHANT_INITIATED | PAYMENT_LINK) F7'de sağlayıcıdan bağımsız yazıldı; iyzico kodu henüz yok. Uyanış Akademi'de çalışan PayTR entegrasyonu (iFrame token, callback hash, test modu, callback IP allowlist) mevcut — uyarlanır.
- **Karar:** F8'de `PayTrProvider` yazılır: checkout = PayTR **iFrame API** (token; `merchant_oid` = Payment.conversationId; sepet/kullanıcı/IP bilgileri; `test_mode`), callback `POST /api/v1/payments/paytr/callback` (hash = base64(HMAC-SHA256(merchant_oid+merchant_salt+status+total_amount, merchant_key)); "OK" yanıtı; IP allowlist Setting `payment.paytrCallbackAllowedIps`; WebhookEvent idempotency), iade = PayTR İade API, kayıtlı kart / tekrarlayan tahsilat = PayTR **Kayıtlı Kart (utoken/ctoken)** API'si (merchant onayı gerekir) → `MERCHANT_INITIATED` stratejisi; onay yoksa/verilene kadar `PAYMENT_LINK` stratejisi = PayTR **Link API** (link oluştur/sil, callback aynı). Ayarlar grubu `payment`: provider (paytr|manual), paytrMerchantId, paytrMerchantKey (secret), paytrMerchantSalt (secret), paytrTestMode, paytrCallbackAllowedIps, storedCardEnabled (onay), nonThreeDsGranted. iyzico adaptörü P2 (aynı arayüz).
- **Sonuçlar:** F8 kapsamı: PayTrProvider + callback + link + kayıtlı kart + iade; checkout sayfasında kart formu yerine PayTR iFrame (ADR-0003 istisna 1 — konteyner aynı). Kullanıcı aksiyonları: PayTR mağaza hesabı + test bilgileri (merchant id/key/salt), **kayıtlı kart/tekrarlayan tahsilat onayı** başvurusu, callback URL'sinin PayTR panelinde tanımlanması (F10b'de canlı URL), komisyon/taksit ayarları. Abonelik tahsilatı onay gelene kadar ödeme linki ile çalışır (lansmanı bloklamaz).
